# TLCD 1.0

**TLCD 1.0：面向自动驾驶交通法规合规性研究的事件级真实道路数据集**

[English](README.md) · [数据说明](DATASET_INFO.md) · [处理代码](code/) · [样本数据](samples/) · [论文材料](manuscript/) · [统计结果](statistics/)

TLCD 1.0 面向交通法规合规性、自动驾驶安全、驾驶行为监测与安全导向数据挖掘研究。数据由一辆一汽红旗 EH7 研发样车在南京和长春的高速公路及城市快速路真实交通环境中采集，并采用事件触发方式保存与法规相关的关键时间窗口。

## 数据集亮点

- 共 **5,173 条事件级记录**，来源于 **2,034.94 km、35.18 h** 的真实道路测试。
- 覆盖南京、长春两座城市。
- 包含最高限速、最低限速、跟车距离、横向距离、变道、连续变道、道路标线合规和超车等 **8 类事件**。
- 覆盖 **17 条适用法规条款**及其机器可执行监测逻辑。
- 每条事件包含覆盖 6 个观察方向的 7 路 30 Hz HEVC/MP4 视频，以及 100 Hz 自车、融合目标、地图、证据链和事件摘要数据。
- 同时包含自动驾驶与人工驾驶数据。
- 最终事件级合规标签经过人工复核；VLM 生成的场景描述和驾驶建议仅作为辅助文本，不参与最终标签确定。

## 数据采集与记录

采集平台集成 7 个摄像头、3 个激光雷达、5 个毫米波雷达、GNSS/INS、高精地图和车载计算单元。外置树莓派以 100 Hz 运行交通法规合规性监测算法，并通过事件触发信号控制工控机回取触发前缓存、继续采集触发后数据，形成类别相关的精确事件窗口。

公开数据包含由原始相机流生成的 7 路事件视频，以及自车、目标、地图、证据链和事件摘要等结构化数据；不包含连续原始相机记录、原始激光雷达、原始毫米波雷达和原始 GNSS/INS 测量。

## 仓库内容

本仓库包含数据说明、论文材料、统计与质量检查结果，以及 [`code/`](code/) 下的自定义处理代码。公开主处理链从 S5 开始：S5 生成三类结构化 CSV，S6 构建证据链，S7 生成 `record.json`；S8 及以后的一次性修补代码统一放在 [`code/event_processing/patches/`](code/event_processing/patches/) 并逐项说明。S1–S4 不上传，因为论文所描述的采集输出已经按事件单元存储。绘图程序不包含在公开代码中。

## 样本与完整数据申请

GitHub 样本 Release 按“南京/长春 × 8 类事件”各提供 1 条完整事件，共 16 条。每个样本保留结构化文件和最终 7 路 30 Hz 视频。样本清单、校验值和下载方式见 [`samples/README.md`](samples/README.md)。当前视频属于临时版本，后续可由脱敏版本替换；使用时应记录 Release 标签或文件校验值。

申请完整数据集，请联系 [hong_wang@mail.tsinghua.edu.cn](mailto:hong_wang@mail.tsinghua.edu.cn) 或 [zhao_cx25@mails.tsinghua.edu.cn](mailto:zhao_cx25@mails.tsinghua.edu.cn)。

- 邮件标题：**[Apply for TLCD] name_country(region)_organization**
- 正文请说明院系或机构、研究方向、具体用途以及申请的数据范围。
- 项目组将对申请逐项审核；是否批准及传输条件取决于相关隐私、授权和数据发布审查。

完整视频数据不进入普通 Git 历史，以保持仓库可克隆和维护。

## 数据质量

- 共发现 5,174 个候选事件目录，其中 5,173 个包含可用的 JSON 事件记录。
- 纳入数据集的 JSON 均可正常解析。
- 所有纳入事件均具有可识别的驾驶方式、事件级合规标签、适用法规 ID 和法规状态。
- 1 个缺少有效 `record.json` 的候选事件目录未纳入统计。
