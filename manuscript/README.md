# Manuscript materials

This directory contains the current work-in-progress LaTeX manuscript source, bibliography, and scientific figures for TLCD 1.0. The source may include incomplete sections and author-side TODO comments; it is provided for project transparency and collaboration and should not be treated as a formally published article.

The compiled manuscript is intentionally omitted from the repository until the author list, affiliations, acknowledgements, funding, data DOI, and licenses have been finalized. The draft source exposes only the currently confirmed repository maintainer; placeholder names and email addresses from the journal template have been removed.
