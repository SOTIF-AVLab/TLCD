# Scene-diversity tables

This directory contains machine-readable tables supporting the TLCD scene-diversity analysis.

- `category_scene_counts.csv`: scene counts by event category.
- `classification_qa.csv`: classification quality checks.
- `special_scene_by_category.csv`: special-scene distribution by event category.
- `special_scene_matrix_counts.csv`: count matrix for special-scene attributes.
- `special_scene_matrix_percent.csv`: percentage matrix for special-scene attributes.

The narrative summary is available in [`../scene_diversity_statistics.md`](../scene_diversity_statistics.md).
